# PyChain — Bitcoin Simulator

A Bitcoin-like blockchain simulator built in Python.

## Features
- Block mining with Proof of Work
- UTXO-based transactions
- P2PKH Script verification
- Multi-wallet support
- Transaction history
- Block explorer

## Run
```bash
python -m Blockchain.Backend.core.blockchain
```

## Stack
- Python
- Flask
- Elliptic Curve Cryptography (secp256k1)
